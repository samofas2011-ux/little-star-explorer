# Explorador de estrellas — Español / English

## En una tablet (recomendado)

1. Sube la carpeta `tablet` completa a tu web con HTTPS, sin cambiar sus archivos.
2. Abre `tablet/index.html` en Safari (iPad) o Chrome (Android) con internet.
3. Pulsa **Sin internet** y espera **Listo para usar sin internet en este dispositivo ✓**. Si no aparece, no está guardado todavía.
4. iPad: **Compartir → Añadir a pantalla de inicio**. Android: **menú ⋮ → Añadir a pantalla de inicio / Instalar aplicación**.
5. Abre el nuevo icono una vez con internet. Activa el modo avión, cierra y vuelve a abrir el icono para comprobar que carga.

Después de guardarlo, el mapa, las 88 constelaciones, las 5.044 estrellas, las historias y ambos idiomas funcionan sin internet. Selecciona **Español** o **English** arriba. La configuración y los descubrimientos se guardan localmente cuando el navegador lo permite.

La lectura en voz alta usa las voces del dispositivo y prefiere una voz local del idioma elegido. Instala una voz española para usarla sin internet; algunas voces requieren conexión. Si el audio no funciona, todo el texto sigue disponible.

No borres los datos del sitio si quieres conservar la copia y tus descubrimientos. El sistema también puede borrar almacenamiento para liberar espacio; en ese caso, abre la página con internet para guardarla de nuevo. Los enlaces de créditos requieren internet.

## Archivo único para computadora

Abre `explorador-estrellas.html` en Chrome, Safari, Edge o Firefox. Incluye todo el contenido y funciona desde el disco sin conexión y sin instalar nada. También puedes subirlo a una web.

En iPad, la vista previa de HTML en Archivos puede no ejecutar JavaScript. Usa la instalación en pantalla de inicio descrita arriba para jugar de forma fiable sin conexión. En Android, si el gestor de archivos no permite abrir HTML interactivo en el navegador, usa también la versión instalada.

## Tablet installation (English)

Upload the complete `tablet` folder to an HTTPS website. Open `tablet/index.html` online in Safari on iPad or Chrome on Android. Tap **Use offline**, and wait for **Ready for offline use on this device ✓**. Add it to the home screen using Safari's Share menu or Chrome's menu. Open the new icon once online, then test reopening in airplane mode.

The complete atlas and both languages are cached locally. No account is built into the downloadable app. The separate Sites-hosted preview is private and may require the owner's sign-in for the initial visit. For a child's independent installation, host the supplied folder on your own website.

On desktop, open `explorador-estrellas.html` directly in a browser. It needs no server or internet. Read-aloud depends on installed device voices. Browser data removal or storage eviction can remove the installed cache and local progress; revisit online if necessary.

## Datos / Data

Es un atlas de todo el cielo, no una vista en directo para tu ubicación. / This is a whole-sky atlas, not a live sky for your location.

Data: Olaf Frohn's d3-celestial, https://github.com/ofrohn/d3-celestial. The full BSD notice is embedded in each HTML file. Constellation names and line figures use the existing catalog; Spanish descriptions are included locally.
